# Trilha

A trilha é dividida em mundos (`mNN-slug/`), cada um com fases (`fNN-slug/`) e fechado por um chefe (`chefe-slug/`). Progresso, XP e título atual ficam em [`PROGRESSO.md`](PROGRESSO.md); conceitos usados, em [`GLOSSARIO.md`](GLOSSARIO.md). Modelos de enunciado em [`templates/`](templates/).
