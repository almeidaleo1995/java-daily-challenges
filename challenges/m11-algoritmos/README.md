# Mundo 11 — Algoritmos
> Um laço que funciona não é o mesmo que um laço que escala; aqui o alvo é a complexidade, não só o resultado.

- **Busca binária** — O(log n) cortando o espaço de busca pela metade a cada passo.
- **Recursão / divisão e conquista** — resolver quebrando em subproblemas menores.
- **Memoização** — guardar resultado já calculado num `Map` para nunca recalcular.
- **Dois ponteiros** — percorrer um array ordenado uma vez só, dos dois lados.
- **Janela deslizante** — manter uma soma parcial em vez de somar tudo de novo a cada posição.
- **Programação dinâmica** — construir a resposta de baixo para cima, guardando os passos intermediários.

**Chefe:** Mercadinho v9: Troco Mínimo — a menor quantidade de moedas para fechar um valor.
